About Dataset

This dataset contains clean tabular records for machine learning model training and predictive analytics:

  • house_price_dataset.csv: 1,000 real estate properties with columns including Area_sqft, Bedrooms, Bathrooms, Age_years, Distance_to_city_km, Floor_number, Parking_spaces, Locality_rating, Furnishing_status, and Price_Lakhs.
  • CART.csv: Classification and Regression Tree credit history dataset with Age_Group, Credit_History, and Loan_Status.
  • regression_tree.png: High-resolution visual decision tree illustrating optimal feature split thresholds.
  • elwin1.py to elwin9.py: Complete regression modeling scripts performing train/test splits, model fitting, R² and MSE evaluation, and scatter plot visualizations.
